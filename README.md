# 🎵 Musical Doodle  

Musical Doodle is my personal project where I aim to recreate an audio streaming platform. The goal is to deepen my understanding of **frontend development** while refining my **backend development** skills.  

---

## 🚀 Technologies Used  

### Frontend  
- **React**: For building dynamic and interactive user interfaces.  
- **Tailwind CSS**: For styling with utility-first CSS.  

### Backend  
- **Python**: For creating a robust and scalable backend system.  

---

## 🎯 Purpose  

This project is a learning playground to:  
- Explore modern **frontend frameworks** and design principles.  
- Improve **backend development** skills by building RESTful APIs and handling user interactions.  
- Work with a stack that combines **React**, **Tailwind CSS**, and **Python**.  

---

## 🛠️ Current Features  

- Audio streaming functionality.  


---

## 🚧 Work in Progress  

Future goals include:  
- Implementing user authentication and roles (e.g., Creator and Listener).  
- Adding audio metrics like streams, likes, and favorites.  
- Enabling category-based filters and recommendations.
- Tag-based audio categorization and filtering.  
- A sleek and minimal user interface.
